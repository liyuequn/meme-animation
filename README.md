# 墨刃 Runtime

《阳寿伏妖》表现手法对标的原创动态漫纵向切片。项目不复用原作人物、剧情或画面资产，只验证其核心导演语言能否被结构化执行。

## 当前闭环

- 8 个可寻址 Shot
- Shot DSL 驱动镜头、角色和 VFX
- 时间线播放、拖动和局部参数修改
- Canvas 实时录制并由 FFmpeg 转码为 MP4
- 生成的 MP4 同时保存到 `exports/`

## 运行

```bash
npm install
npm run dev
```

打开 `http://127.0.0.1:4173`。
