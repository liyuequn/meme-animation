# 正式角色素材门槛

正式验收人物必须同时满足：

1. 中国古风/武侠造型，不以日式武士或西幻铠甲替代。
2. 许可覆盖修改、商用和成片分发，作者身份与原始设计权利可信。
3. 可下载 FBX/GLB/Blend，包含完整人形骨骼、蒙皮和基础面部能力。
4. 服装拓扑允许大幅动作；长袖、衣摆、头发可另加布料/辅助骨骼。
5. 面数和贴图可优化到批量镜头生产，而不是只能做单张展示。
